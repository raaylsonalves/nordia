# ADR 001 — Nordia's visual rebuild

Status: accepted, 2026-09-23.

## Context

The user asked for a fresh institutional site using Wemotion as the main visual reference, with strong motion, and explicitly allowed generated imagery. Nordia already had a Next.js repository, real brand geometry, business copy and contact destinations. Earlier attempts based on existing layouts had not met the requested visual direction.

## Decision

Keep the existing Next.js application and replace the home page composition. Use a locally hosted Rethink Sans pair, Wemotion's measured light canvas, black type, oversized offset headlines and central expanding media. Keep Nordia's exact two-path N and orange `#f74b01`. Generate two conceptual material images of metal and an orange connector; label them as illustrative, with no implied client case studies. Animate the headline join and image expansion with GSAP; keep the rest of the site in natural flow with limited parallax and native `<details>` service disclosures. Use Radix Dialog for an accessible mobile menu and expose a movement reduction control.

## Why

The original mark and contact details keep the result identifiable as Nordia. Measured reference tokens make the Wemotion influence concrete while original copy and imagery make the page specific to Nordia. Native scrolling, small client components and local font/image assets make the page work on desktop and mobile without depending on external media during runtime.

## Alternatives considered

- Adapting the previous page sections: rejected because the user explicitly asked to start the composition over.
- Importing Scrollcraft's standalone animation engine: rejected for this Next.js page because its current runtime does not expose unmount cleanup. The project's GSAP dependency already supports reversible match-media lifecycles.
- Pinning the visual during scroll: tested as a design direction, then dropped to keep the visitor's native scroll and avoid empty travel on phones.

## Consequences and checks

The old page components remain in the repository as unused historical code; the new page does not import them. Concept imagery is an illustration of the offer, not evidence of delivered projects. Desktop, mobile and tablet were inspected in the browser, with no horizontal overflow. TypeScript, ESLint and production build completed. The final visual review should be repeated with actual Nordia content or new approved photographs if the business later provides them.
